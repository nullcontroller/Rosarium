# 第3段階の人工計算検算

Python 3.10以上・標準ライブラリのみ。リポジトリルートで `python scripts/math-phase-three/verify.py` を実行する。結果はJSONとして標準出力へ出る。Pythonバージョン、乱数シード20261126、許容誤差、有限差分の刻みを結果へ記録する。外部モデル・GPU・APIは使用しない。

|系統|独立した照合|対象外|
|---|---|---|
|N07|分数の一括事後と浮動小数点の逐次更新、順序反転、解析勾配と有限差分、回帰更新と内積集約|実LLMの機構・Few-shot品質|
|N09|選択後再正規化と選択集合softmax、Top-1/2の出力・負荷、再正規化あり／なしの主損失ゲート勾配と有限差分、補助損失勾配と有限差分|負荷分散の訓練成功・GPU速度|
|N10|ZOH解析解と中点数値積分、A=0、再帰と畳み込み、二状態、scanの木状合成と逐次更新|密行列一般の行列指数、Mambaの完全再現|
|N11|遷移行列の周辺化と全経路列挙、Bayes逆確率、異なる段数、経路ELBOとKL分解|学習された復元器・実文章の品質|

通常の絶対誤差は1e-10、有限差分・数値積分は1e-9。assertが失敗すればプロセスは非0で終了する。図解は `python scripts/math-phase-three/render.py` で生成する。SSMの減衰図とICLの事後値は同じ検算関数の値を使う。
