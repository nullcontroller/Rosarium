利用実績と、企業が得る価値の違い

## はじめに｜AIを導入しただけで成功と言えるのか

企業がAIを導入するとき、その成果はどのように評価されるのだろうか。

利用者数、利用回数、作業時間の短縮、AIを用いたシステムの開発件数。

これらは、AI活用の状況を把握するための指標になる。

しかし、私は一つ疑問を感じている。

AIが使われていることは、企業にとっての成功を意味するのだろうか。

例えば、AIによる問い合わせ対応システムを導入し、多くの従業員が利用するようになったとする。

それでも、問い合わせ対応の負担が減らず、回答品質も改善していなければ、何をもって成功と判断するべきなのだろうか。

本稿では、AIの導入や利用という活動と、企業が実際に得る成果を区別し、成功の評価方法を考える。

## 1. AI導入の成功には、異なる段階がある

AI導入の成果は、次の四つに分けて考えられる。

| 段階 | 確認すること |
| --- | --- |
| 導入 | AIを利用できる状態になったか |
| 利用 | 対象業務で継続的に使われているか |
| 業務改善 | 業務の品質や生産性が向上したか |
| 事業成果 | 企業が目指す価値を実現したか |

この分類は、成果を整理するための枠組みであり、すべての企業が順番に到達する成熟度モデルではない。

例えば、AIを利用した問い合わせ対応システムを考えてみよう。

システムが完成すれば、導入は成立する。

従業員が日常業務で利用するようになれば、利用も成立する。

さらに、問い合わせ対応時間が短縮され、回答品質も維持または向上していれば、業務改善の成果を確認できる可能性がある。

そして、その改善が顧客対応能力の向上や費用削減など、当初の事業目的につながれば、事業成果として評価できる。

重要なのは、これらを同じ成功として扱わないことである。

AIを導入したこと、利用されたこと、業務が改善したこと、事業目的を達成したことは、それぞれ異なる。

## 2. 工数削減が、利益の増加につながるとは限らない

AI導入の効果として、作業時間の短縮が示されることがある。

しかし、個別作業の時間が短縮されても、業務全体の工数が削減されたとは限らない。

例えば、AIが問い合わせの回答案を短時間で作成できても、その内容の確認や修正に時間がかかる場合がある。

したがって、回答案の生成時間だけでなく、確認、修正、再問い合わせへの対応まで含めて評価する必要がある。

さらに、業務全体の工数が削減されたとしても、それが利益の増加に直結するわけではない。

削減した時間を別の業務に活用できるのか。処理できる問い合わせの件数が増えるのか。実際の費用削減につながるのか。

こうした条件によって、経営上の効果は変わる。

また、AIには利用料金だけでなく、教育、運用、品質確認、保守、セキュリティ対策などの費用も発生する。

作業時間の短縮を、企業利益の増加と同一視することはできない。

## 3. 成功条件は、導入する前に決める

AI導入の成功を評価するには、何を達成したいのかを事前に明確にする必要がある。

例えば、問い合わせ対応業務を改善するのであれば、次のような目的が考えられる。

- 対応完了までの時間を短縮する。
- 回答の正確性を高める。
- 同じ問い合わせの再発を減らす。
- 担当者の負担を軽減する。

これらは似ているようで、同じ目的ではない。

対応時間を短縮しようとすれば、回答品質に影響する可能性がある。品質確認を強化すれば、対応時間が増える場合もある。

そのため、目的とともに、何を犠牲にしてはいけないのかという条件も定める必要がある。

例えば、対応時間の短縮を目標とする場合でも、回答の正確性を維持することを必須条件にできる。

また、評価には比較対象が必要である。

AI導入前後の単純な比較では、問い合わせの難易度や件数、担当者の経験などの違いが結果に影響する場合がある。

可能であれば、条件の近い業務や期間を比較し、AI導入以外の要因も考慮することが望ましい。

成功条件と評価方法が曖昧なままでは、導入後に成果を判断することも難しくなる。

## 4. 数字に表れにくい価値もある

AI導入の価値は、すべて金額で表せるわけではない。

例えば、担当者が必要な情報を見つけやすくなることや、判断に必要な知識が共有されることにも価値がある。

品質の安定、リスクの低減、新しい業務への対応能力の獲得なども考えられる。

また、導入初期には利益が出なくても、将来の活用に必要な技術や運用能力を獲得できる場合がある。

したがって、短期的な投資対効果だけで、すべてのAI導入を評価することは適切ではない。

ただし、数字に表れにくいからといって、評価を省略してよいわけではない。

例えば、知識共有が目的なら、必要な情報を探せるようになったか。品質向上が目的なら、誤回答や手戻りが減ったか。

目的に応じて、観察できる変化を確認することはできる。

金額に換算できない価値も評価対象になる。しかし、価値があると主張することと、その価値を確かめることは別である。

## 5. 成功しなかったとき、どう判断するか

AIを導入しても、期待した成果が得られない場合がある。

そのとき、利用を続けることが常に正しいとは限らない。

業務への適用範囲を変更する。利用する技術を変更する。業務手順を見直す。あるいは、導入自体を中止する。

こうした判断も、AI活用に含まれるはずである。

そのためには、導入前から次の三つを考えておきたい。

| 判断 | 確認すること |
| --- | --- |
| 継続 | 期待した成果が得られているか |
| 改善 | 方法を変えることで成果を高められるか |
| 撤退 | 継続する合理性が失われていないか |

ただし、短期的な成果が出なかったという理由だけで、直ちに撤退するべきとは限らない。

技術の習得や業務への定着に時間が必要な場合もある。

重要なのは、成果が出ていない理由を確認し、あらかじめ定めた目的と条件に照らして判断することである。

AIを使い続けることではなく、AIを使い続ける合理性を評価することが重要である。

## おわりに｜AI導入の成功を再定義する

AIの導入数や利用率は、取り組みの状況を知るために役立つ。

しかし、それだけでは企業が価値を得たかどうかは分からない。

作業時間が短縮されても、品質や費用への影響を確認する必要がある。

また、短期的な利益に表れなくても、将来に向けた知識や能力の獲得に価値がある場合もある。

だからこそ、AI導入の成功を一つの数字で判断するのではなく、当初の目的と照らし合わせる必要がある。

AI導入の成功とは、AIをどれだけ使ったかではなく、事前に定義した目的に対して、検証可能な価値を生み出したかどうかで判断するべきではないだろうか。

そして、期待した価値が得られないなら、方法を変更することも、利用を中止することも選択肢になる。

最後に、一つの問いを残したい。

私たちは、AIの導入を成功させようとしているのだろうか。それとも、AIによって事業の目的を達成しようとしているのだろうか。
